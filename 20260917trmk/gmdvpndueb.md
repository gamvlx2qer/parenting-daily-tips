# 签字进入“试管婴儿”治疗周期前后需要注意些什么？

> 更新时间：2026-09-17 (UTC+8)

****

原创内容，转载请注明出处
1
**签字日前**

签字日前需按医生要求将门诊医生审核过的所有的检查结果复印留存，并将检查结果原件、双方结婚证复印件、双方身份证复印件、准生证明 ( 未生育者需提供当地计划生育部门提供的计划生育证明，于当地乡镇街道办理，需盖计划生育办公室的章；已生育或领养等有孩者需提供当地计划生育部门提供的二胎准生证，具体在就诊时医生会明确告诉您 ) 按照就诊医生的要求交给就诊医生或者开单交单处。
2
**签字当天**

1. 签字前夫妻双方要在信息录入处进行**身份证**的扫描。

2. 签字日夫妻双方需要一起到场。需要携带：

**① 夫妇双方身份证原件**

**② 双方结婚证原件**

**③ 所有门诊病历本**

**④ 挂号单**

**⑤ 如为生育二胎者，请携带二胎准生证原件**

3. 签字日夫妻双方需在宣教室观看宣教录像，认真了解试管婴儿的流程及注意事项，在相关知情同意书上签名，并听从医生的安排，记清药物的使用及 B 超、抽血的时间。

4. 签字后夫妻双方要在信息录入处**录取指纹，夫妻双方拍照，进行结婚证的扫描**。
3
**药物方面**

- 
药物若于当地注射，必须在正规医院进行注射操作。

- 
每日注射时间最好相对固定，以保证血药浓度波动不大。

- 
**于当地注射时需要注意**：皮肤严格消毒以避免皮肤感染；注射部位、剂量要正确。

- 
**在本中心进行注射，需携带**：病历、挂号单、注射单，签字时医生给患者的 《 要求做试管婴儿患者须知 （ 一 ） 》 。

- 
**不要**进行私人药物交易，以免引起交叉感染，危害健康及安全。

4
**进周期后的注意事项**

1. 进周期后，应避免劳累，尽量避免感冒，发烧，腹泻等不适。

2. 治疗过程中，若无不适不需门诊；若有腹痛、腹胀等不适请及时就诊；医生若发现异常情况（ 卵巢反应不良、出现囊肿需要处理、卵泡生长不均需要穿刺等 ）会及时与您沟通，请不要担心。

3. 进周期后的患者，医生会给您安排抽血及 B 超的时间，抽血当天需空腹。若周一至周五来抽血做 B 超，请于下午 2：00 （ 夏令时为下午 2：30 ） 后在二楼宣教室等候护士发药。周六、日抽血及 B 超上午结束，请于上午 10：00 后三楼门诊大厅等候护士发药。

4. 取卵前一日，医护人员会在 1 号楼二楼向您详细说明取卵及移植前后的注意事项。

5. 试管婴儿周期平均所需时间约为 1 个月，因为每位患者的情况、方案各不相同，且对药物反应性亦不一样，周期长短也会不相同。同一天签字的患者未必同一天取卵移植，相互比较并没有意义。

6. 病假条：请您周一至周五于本中心门诊就诊时开假条，周六周日本中心无门诊。
