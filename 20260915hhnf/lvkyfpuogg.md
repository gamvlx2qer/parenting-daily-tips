# 看望骨折病人买哪三样水果

> 更新时间：2026-09-15 (UTC+8)

看望骨折病人可选择香蕉、橙子、苹果等水果，均较为适合骨折病人食用，且并不只有三种。但无论哪种水果，骨折病人食用时都需注意量，并注意观察个体情况变化。

**1、香蕉**

- 富含营养：香蕉富含钾元素，有助于维持身体正常的电解质平衡。骨折病人在恢复期间可能活动量减少，容易出现电解质紊乱，适当食用香蕉可以起到一定的调节作用。
- 易于消化：骨折病人往往需要长时间卧床休息，这可能会导致肠胃蠕动减慢，出现消化不良等问题。香蕉质地柔软，容易消化，不会给肠胃带来过多负担。
- 方便食用：香蕉无需清洗削皮等复杂操作，病人可以很方便地食用，随时补充能量。

**2、橙子**

- 维生素C对于伤口愈合和骨骼修复起着重要作用，橙子中含有丰富的维生素C，可以促进骨折部位的组织修复和再生，加快病人的康复进程。
- 橙子口感酸甜，清爽多汁，能够刺激病人的食欲。在骨折恢复期间，病人可能因为疼痛或心情不佳而食欲下降，橙子可以起到开胃的作用。

**3、苹果**

- 营养全面：苹果富含多种维生素和矿物质，如维生素A、B族维生素、钙、磷等，对于骨折病人的身体恢复都有一定的益处。
- 促进肠道蠕动：苹果中含有丰富的膳食纤维，可以促进肠道蠕动，预防便秘等问题。骨折病人由于活动受限，容易出现便秘，适当食用苹果可以改善肠道功能。
- 储存方便：苹果相对比较耐储存，不容易变质，可以在病人身边放置较长时间，方便病人随时食用。

住院病人过量吃水果可能导致血糖升高，尤其对糖尿病患者不利，还可能引起肠胃不适，如腹痛、腹泻等，影响身体恢复。还有水果过量食用可能与药物相互作用，影响药效发挥。
