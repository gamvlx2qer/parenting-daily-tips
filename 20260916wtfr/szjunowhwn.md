# 市领导到市人民医院调研人才工作------ 搭建发展平台 集聚医疗人才

> 更新时间：2026-09-16 (UTC+8)

2月22日下午，市委常委、组织部部长陈然率队到市人民医院调研人才工作，强调要总结经验，发挥优势，搭建人才成长发展平台，强化人才硬件软件保障，推动我市人才工作再上新台阶。

　　陈然一行首先实地参观了市人民医院“国家住院医师规范化培训基地”和“拔尖人才工作室”，随后召开座谈会，听取市人民医院人才工作情况的汇报。据不完全统计，我市近年引进的高端医疗人才约90名，其中博士研究生4人，硕士研究生64人，副高以上资格专业技术人员26人，全市卫生人才队伍不断壮大。市人民医院作为我市人才培养示范点，在探索人才外引、内培、使用立体化模式上取得较大成果。

　　市人民医院院长谢军在向市委常委、组织部部长陈然介绍规培基地的建设情况

　　

　　陈然对市人民医院在人才工作中取得的成绩表示充分肯定，强调人才工作要做到“四个有机结合”。人才培养与引进有机结合，畅通人才成长通道，鼓励青年医生接受再培训、再教育；医疗与研究有机结合，发挥拔尖人才的领头羊作用，促进医疗卫生事业长足发展；激励与保障有机结合，建立和完善激励机制，制定科学合理的考核制度，更好地发挥人才的作用；医德教育与医疗水平提升有机结合，构建学习型的医疗团队，通过教育培训提升医疗人才的爱心、责任心和服务群众意识。
